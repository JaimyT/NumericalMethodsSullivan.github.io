# NumericalMethodsSullivan.github.io

Inquiry Based Numerical Methods Textbook
This is a textbook for introductory numerical methods.  See the front matter of the book for licensure information.

Edited by Jaimy Tomlinson

----

Each chapter is a self-contained html document with minimal extraneous data. Bookmarks in each chapter correspond to identified elements. Upon entering an extension to the page url, if a bookmark is supplied, the page will scroll to the corresponding element.
To make links as clean as possible, the url format is as follows:
https://some.web.domain/#{chapter index}/{bookmark id}
Additionally, if the chapter index is left blank like so:
.../#/exr1.1
it will be filled in with the currently opened chapter. This way, links within a chapter do not have to be changed if the chapter location is altered.
Bookmarked elements will be registered to the table of contents via a node.js build utility script before publishing. However, bookmarks can also be added or edited manually. These overrides will eventually include a system for automatic merging with the script.
At the moment, some of the links in the revised documents is a mess, as the standard was not fully defined at the time they were written. These will need to be updated later.
